# 使用 Pixel Companions

[English](../usage.md) | 中文 | [Русский](../ru/usage.md) | [Tiếng Việt](../vi/usage.md) | [日本語](../ja/usage.md) | [한국어](../ko/usage.md)

这一页是我给自己的插件写的日常使用指南。如果插件还没装，请先看
[installation.md](installation.md)：安装只需一条 `dsh plugin` 命令加一次页面刷新。下面的
一切都在浏览器里发生，可选的桌面窗口放在最后。

## 第一次运行

bundle 安装完成并重新加载页面后，伴侣会出现在窗口右下角、输入框区域的上方。它绘制在官方
`shell.overlay` 槽位里，因此在对话、设置和插件页都保持可见，并且跨页面导航不会消失。你不
需要打开对话：没有会话时伴侣只是待机和睡觉。

精灵上方的小字幕会用你选择的语言标出当前场景。把鼠标悬停在精灵上会显示齿轮按钮（⚙）；如果
对话已打开，还会显示消息输入框。

## 移动它

用鼠标左键、手指或触控笔拖动精灵本身。按下后移动不到几个像素是点击而不是拖动：单击会对
当前场景做出反应，快速再点一次会得到更强的反应，右键会打开设置面板（齿轮按钮和 Shift+F10
也一样）。

位置会被限制在窗口内，在窗口缩放或伴侣改变大小时重新检查，并保存在本浏览器的
`localStorage` 中（键为 `kappy.pixel-companions.ui.v1`）；重新加载页面后会恢复。如果伴侣
跑到了别扭的位置，打开齿轮面板选择**重置位置**，它就会回到自动右下角的位置。

## 互动

伴侣会回应你的关注，但反应绝不会改变会话、错误信号或完成报告。

- 左键单击：温和的、贴合场景的反应——被摸摸、被吓一跳、等待时可怜巴巴、完成时欢呼等等。
- 左键双击：更强的反应——打字或工作时不耐烦、阅读或调试时被打扰、空闲时害羞、被吵醒时生气。
- 右键：打开设置面板；齿轮按钮和 Shift+F10 也可以。
- 错误：伴侣会哭。单击会把它安慰成带泪的可爱表情，泪痕会一直保留到错误消失。
- 真实 agent 连续工作十分钟：它会显得筋疲力尽；单击会得到情绪化的反应，双击会得到生气的反应。
- 反应是临时的，结束后回到 agent 的场景。开启减少动态效果或关闭动画时使用静止 PNG 帧，
  精灵下方的对白已本地化为全部六种语言。

## 快速发送消息

对话打开时，把鼠标悬停在伴侣或完成报告上：消息输入框会直接出现在报告下方（没有报告时则
出现在伴侣下方）。最多输入 2000 个字符，按 **Enter** 或 ➤ 按钮即可把消息发送到当前会话。
按 **Escape** 会清空输入框并关闭它。

发送后你主输入框里的草稿会恢复，在这里打字也绝不会改变伴侣的场景。拖动时和设置面板打开时
输入框会隐藏；它需要已打开的对话。

## 阅读回答报告

一轮结束时，伴侣会切换到完成场景，并在下方保留一份**粘性**报告：最终回答的第一行加上
**详情**按钮。它会一直保留，直到你把鼠标悬停到伴侣上（约 0.3 秒停留）或新的一轮开始，
所以即使你转头看向别处也不会错过。

**详情**会打开一个可滚动面板，以纯文本显示完整最终回答：保留换行，最多 8000 个字符，不
渲染 HTML 或 markdown。用 ✕ 按钮、**Escape** 或点击面板外部关闭。面板打开时会替换
报告/输入卡片。回答文本只留在页面里；只有场景会镜像到可选的桌面窗口。

## 改变它的大小

同一个偏好有两个入口，并且保持同步：

- 齿轮面板中的**大小**滑块；
- **设置 → 通用 → 伴侣大小**。

滑块范围是 50% 到 200%，步进 5%；带 − / + 按钮、实时百分比和 50/100/150/200% 预设按钮。
精灵按真实的缩放像素尺寸渲染（100% 时为 152×98），点击区域、字幕、报告列和详情面板都会跟随
它。改变大小时，保存的位置会自动重新限制。

## 角色、语言、动画、显示

齿轮面板里还有角色（**Lumi** 或 **Deepy**）、界面语言、动画开/关（动画 WebP 或静止
PNG）、显示开关，以及带 **Auto** 的 15 个场景预览网格，用于测试。首次运行跟随
`navigator.language`；你选择的语言也会切换伴侣的字幕。关闭动画是笔记本上最省电的快速做法。

## 可选的桌面窗口

同一个精灵也可以在同机的、始终置顶的小型 GTK 窗口里浮在浏览器之外。它默认关闭，需要
Python 3、GTK 3 和 Pillow：

```sh
sudo apt install python3-gi gir1.2-gtk-3.0 python3-cairo
python3 -m pip install --user Pillow
python3 desktop/companion.py
```

在齿轮面板中勾选**桌面窗口**；该行会显示 **Connected**、**Not running** 或 **Off**。
bridge 只监听 `127.0.0.1:37421`，只传场景、角色、缩放和动画标志——绝不传提示、草稿、消息、
会话 id 或模型输出。右键桌面窗口可以打开它的菜单（角色、大小、始终置顶、重置位置、隐藏 1
小时、退出）。页面必须保持打开才能实时更新。完整指南：[desktop.md](desktop.md)。

## 关闭它

- 不卸载、只隐藏：齿轮面板 → 关闭**显示**，或在**设置 → 插件**里关闭。
- 禁用 bundle：设置 → 插件，或从 `dsh.profile.bundles` 中移除。
- 彻底卸载：`dsh plugin --profile web remove dsh-pixel-companions`。界面恢复原样；不会改动
  配置档以外的文件。
- 桌面窗口是独立进程：从它的右键菜单退出。

## 它能看到什么、看不到什么

伴侣只读取公开的槽位 props：会话运行状态、当前输入阶段、待处理交互、错误标志，以及对话里
已经显示的最终回答。它绝不读取提示文本或你的输入框草稿，除了自己的素材路由和可选的本地
桌面 bridge 之外不发起网络调用。详情和报告只留在页面里。如果你从未启用桌面窗口，页面就
永远不会连接桌面端口。

## 键盘与无障碍

精灵和齿轮都是常规的可聚焦按钮：**Tab** 可以到达它们，**Enter** 或 **Space** 打开设置
面板。**Escape** 关闭面板和详情视图，点击外部也一样。滑块和选择框都可以用键盘操作，报告
通过 `aria-live` 播报，详情面板是带标签的对话框。

诊断：[troubleshooting.md](troubleshooting.md)。场景规则：
[scenes.md](scenes.md)。
