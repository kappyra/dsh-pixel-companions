# Pixel Companions の使い方

[English](../usage.md) | [中文](../zh/usage.md) | [Русский](../ru/usage.md) | [Tiếng Việt](../vi/usage.md) | 日本語 | [한국어](../ko/usage.md)

このページは、私のコンパニオンの日常的な使い方をまとめたガイドです。まだプラグインを
インストールしていない場合は、まず [installation.md](installation.md) から始めてください。
インストール全体は `dsh plugin` コマンド 1 つとページの再読み込みだけで済みます。以下の
内容はすべてブラウザ内の話で、オプションのデスクトップウィンドウについては最後に説明
します。

## 初回起動

バンドルをインストールしてページを再読み込みすると、私のコンパニオンがウィンドウの右下
付近、コンポーザー領域の上に現れます。公式のフレーム全体用 `shell.overlay` スロットに描画される
ため、会話・設定・プラグインページでも表示されたままになり、ページ移動をまたいで残ります。
開いている会話は必要ありません。セッションがなければ、コンパニオンはただ待機して眠ります。

スプライトの上に小さなキャプションが表示され、選択中の言語でシーン名が示されます。
スプライトにホバーすると歯車ボタン（⚙）が現れ、会話が開いていればメッセージ
入力欄も現れます。

## 動かす

スプライト自体を、マウスの左ボタン、指、またはペンでドラッグします。数ピクセル未満しか
動かない押下はクリックとして扱われ、コンパニオンを動かす代わりに設定パネルが開きます。
そのため、手が少し動いても位置を失うことはありません。

位置はウィンドウ内に保たれ、ウィンドウのリサイズやコンパニオンのサイズ変更のたびに
確認し直され、このブラウザの `localStorage` の `kappy.pixel-companions.ui.v1` に保存され
ます。ページを再読み込みすると復元されます。コンパニオンが扱いにくい場所に来てしまった
場合は、歯車パネルを開いて**位置をリセット**を選ぶと、自動の右下位置に戻ります。

## 手軽にメッセージを送る

会話を開いた状態で、コンパニオンまたは完了レポートにホバーすると、メッセージ入力欄が
レポートの直下（レポートが表示されていないときはコンパニオンの下）に現れます。2000 文字
まで入力し、**Enter** または ➤ ボタンを押すと現在のセッションへ送信されます。**Escape**
を押すと入力欄が空になり、閉じます。

送信後は、メインのコンポーザーの下書きが復元されます。ここで入力しても、私の
コンパニオンのシーンが変わることはありません。入力欄はドラッグ中と設定パネルを
開いている間は非表示で、開いている会話が必要です。

## 回答レポートを読む

ターンが終わると、コンパニオンは完了のシーンに切り替わり、**固定表示**のレポートをその下
に残します。内容は最終回答の 1 行目と**詳細**ボタンです。コンパニオンにホバーする
（約 0.3 秒の滞在）か新しいターンが始まるまで残るので、目を離していても見逃しません。

**詳細**を押すと、完全な最終回答をプレーンテキストで表示するスクロール可能なパネルが
開きます。改行は保持され、最大 8000 文字で、HTML や Markdown のレンダリングは行われません。
✕ ボタン、**Escape**、外側のクリックで閉じます。パネルが開いている間はレポート/入力カード
が置き換えられます。回答のテキストはページ内にとどまり、オプションのデスクトップウィンドウ
へミラーリングされるのはシーンだけです。

## サイズを変える

同じ設定に 2 つの入口があり、両者は同期を保ちます：

- 歯車パネルの**サイズ**スライダー。
- **設定 → 一般 → コンパニオンの大きさ**。

スライダーは 50% から 200% まで 5% 刻みで、− / + ボタン、リアルタイムのパーセント表示、
50/100/150/200% のプリセットチップがあります。スプライトは実際のスケール後のピクセル
サイズ（100% で 152×98）で描画され、ヒットエリア、キャプション、レポートの列、詳細パネル
もそれに追随します。サイズを変えると、保存された位置は自動で再クランプされます。

## キャラクター、言語、アニメーション、表示

歯車パネルには、キャラクター（**Lumi** または **Deepy**）、インターフェースの言語、
アニメーションのオン/オフ（アニメーション WebP か静止 PNG）、表示のスイッチ、テスト用の
**自動**付き 15 シーンのプレビューグリッドもあります。初回起動は `navigator.language` に
従い、選んだ言語はコンパニオンのキャプションにも反映されます。ノート PC のバッテリーを
節約するには、アニメーションをオフにするのがいちばん手早い方法です。

## オプションのデスクトップウィンドウ

同じスプライトは、同じマシン上の常に手前の小さな GTK ウィンドウで、ブラウザの外にも表示
できます。既定ではオフで、GTK 3 と Pillow を備えた Python 3 が必要です：

```sh
sudo apt install python3-gi gir1.2-gtk-3.0 python3-cairo
python3 -m pip install --user Pillow
python3 desktop/companion.py
```

歯車パネルで**デスクトップウィンドウ**にチェックを入れます。行には**接続済み**、
**未起動**、**オフ**が表示されます。ブリッジは `127.0.0.1:37421` のみを待ち受け、運ぶのは
シーン、キャラクター、スケール、アニメーションのフラグだけです。プロンプト、下書き、
メッセージ、セッション id、モデル出力が流れることはありません。デスクトップウィンドウを
右クリックするとメニュー（character、size、always on top、reset position、hide for an
hour、quit）が開きます。ライブ更新のためにはページを開いたままにする必要があります。
詳しいガイド：[desktop.md](desktop.md)。

## オフにする

- アンインストールせずにスプライトを隠す：歯車パネルで**表示**をオフにするか、
  **設定 → プラグイン**を使います。
- バンドルを無効化する：設定 → プラグイン、または `dsh.profile.bundles` から削除します。
- 完全にアンインストールする：
  `dsh plugin --profile web remove dsh-pixel-companions`。UI は素の状態に戻り、プロファイル
  外のファイルには触れません。
- デスクトップウィンドウは別プロセスです。右クリックメニューから終了してください。

## 見えるもの、見えないもの

私のコンパニオンが読むのは公開スロットの props だけです。セッションの実行状態、現在の入力
フェーズ、承認待ち、エラーのフラグ、そして会話にすでに表示されている確定済みのアシスタント
の回答です。プロンプトのテキストやコンポーザーの下書きを読むことはなく、自身のアセット
ルートとオプトインの localhost デスクトップブリッジ以外にネットワーク呼び出しを行いません。
詳細とレポートはページ内にとどまります。デスクトップウィンドウを一度も有効にしなければ、
ページがデスクトップのポートに触れることはありません。

## キーボードとアクセシビリティ

スプライトと歯車は通常のフォーカス可能なボタンです。**Tab** で到達し、**Enter** または
**Space** で設定パネルが開きます。**Escape** はパネルと詳細ビューを閉じ、外側のクリックも
同じ働きをします。スライダーとセレクトはキーボードで操作でき、レポートは `aria-live` で
通知され、詳細パネルはラベル付きのダイアログです。
