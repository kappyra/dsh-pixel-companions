# Pixel Companions 사용법

[English](../usage.md) | [中文](../zh/usage.md) | [Русский](../ru/usage.md) | [Tiếng Việt](../vi/usage.md) | [日本語](../ja/usage.md) | 한국어

저는 이 문서를 제 플러그인의 일상 사용 안내로 썼습니다. 아직 플러그인을 설치하지 않았다면
[installation.md](installation.md)부터 시작하세요. 설치는 `dsh plugin` 명령 하나와 페이지
새로고침이면 끝납니다. 아래 내용은 모두 브라우저에서 일어나며, 선택적 데스크톱 창은 마지막에
다룹니다.

## 첫 실행

번들이 설치되고 페이지를 새로고침하면 컴패니언이 창 오른쪽 아래, 입력창 영역 위에
나타납니다. 공식 프레임 전체 `shell.overlay` 슬롯에 그려지므로 대화, 설정, 플러그인
페이지에서 계속 보이고 페이지 탐색 후에도 유지됩니다. 대화가 열려 있을 필요는 없으며,
세션이 없으면 컴패니언은 그냥 유휴 상태와 수면을 오갑니다.

스프라이트 위의 작은 캡션이 현재 장면을 선택한 언어로 보여 줍니다. 스프라이트에 호버하면
톱니바퀴 버튼(⚙)이 나타나고, 대화가 열려 있으면 메시지 입력창도 나타납니다.

## 옮기기

스프라이트 자체를 마우스 왼쪽 버튼, 손가락, 펜으로 드래그하세요. 몇 픽셀 미만 움직인
누름은 드래그가 아니라 클릭입니다. 클릭 한 번이면 현재 장면에 반응하고, 빠르게 한 번 더
클릭하면 더 강한 반응이 나오며, 오른쪽 클릭하면 설정 패널이 열립니다(톱니바퀴 버튼과
Shift+F10도 같습니다).

위치는 창 안에 유지되고, 창 크기가 바뀌거나 컴패니언 크기가 바뀔 때 다시 확인되며, 이
브라우저의 `localStorage`에 `kappy.pixel-companions.ui.v1` 키로 저장됩니다. 페이지를
새로고침하면 복원됩니다. 컴패니언이 어색한 곳에 있으면 톱니바퀴 패널을 열어
**위치 초기화**를 선택하면 자동 오른쪽 아래 위치로 돌아갑니다.

## 상호작용

컴패니언은 당신의 관심에 반응하지만, 반응이 세션이나 오류 신호, 완료 보고서를 바꾸지는
않습니다.

- 왼쪽 클릭 한 번: 부드럽고 상황에 맞는 반응입니다. 쓰다듬기, 놀란 표정, 기다리는 동안의
  애처로운 표정, 턴이 끝났을 때의 환호 등입니다.
- 왼쪽 더블 클릭: 더 강한 반응입니다. 입력 중이거나 작업 중이면 짜증, 읽기나 디버깅
  중이면 방해받은 표정, 유휴 상태면 수줍음, 잠에서 깨우면 화난 표정입니다.
- 오른쪽 클릭: 설정 패널을 엽니다. 톱니바퀴 버튼과 Shift+F10도 같습니다.
- 오류: 컴패니언이 웁니다. 한 번 클릭하면 귀여운 눈물 맺힌 표정으로 위로되고, 눈물 자국은
  오류가 사라질 때까지 남습니다.
- 실제 에이전트 작업 10분: 지친 표정이 됩니다. 클릭하면 감정적인 반응, 더블 클릭하면 화난
  반응이 나옵니다.
- 반응은 일시적이며 에이전트 장면으로 돌아갑니다. 동작 줄이기 또는 애니메이션 꺼짐
  상태에서는 정적 PNG 프레임을 사용하고, 스프라이트 아래 대사는 6개 언어로 현지화됩니다.

## 빠른 메시지 보내기

대화가 열려 있을 때 컴패니언이나 완료 보고서에 호버하면 메시지 입력창이 나타납니다.
보고서가 보이면 보고서 바로 아래, 보고서가 없으면 컴패니언 아래에 표시됩니다. 최대
2000자까지 입력하고 **Enter** 또는 ➤ 버튼을 눌러 현재 세션으로 보내세요. **Escape**는
입력창을 비우고 닫습니다.

메인 입력창 초안은 전송 후 복원되며, 여기서 입력해도 컴패니언 장면은 바뀌지 않습니다.
입력창은 드래그 중이거나 설정 패널이 열려 있을 때 숨겨지고, 대화가 열려 있어야 합니다.

## 답변 보고서 읽기

턴이 끝나면 컴패니언이 완료 장면으로 바뀌고 그 아래에 **고정** 보고서를 유지합니다. 최종
답변의 첫 줄과 **자세히** 버튼입니다. 컴패니언에 호버하거나(약 0.3초 머무름) 새 턴이
시작될 때까지 유지되므로 잠깐 다른 곳을 봐도 놓치지 않습니다.

**자세히**는 전체 최종 답변을 일반 텍스트로 담은 스크롤 가능한 패널을 엽니다. 줄바꿈이
유지되고 최대 8000자이며 HTML이나 Markdown을 렌더링하지 않습니다. ✕ 버튼, **Escape**,
또는 바깥 클릭으로 닫습니다. 패널이 열려 있는 동안 보고서/입력 카드를 대체합니다. 답변
텍스트는 페이지에 남고 장면만 선택적 데스크톱 창으로 미러링됩니다.

## 크기 변경

같은 환경설정에 대한 진입점이 두 곳 있으며 서로 동기화됩니다:

- 톱니바퀴 패널의 **크기** 슬라이더;
- **설정 → 일반 → 컴패니언 크기**.

슬라이더는 50%에서 200%까지 5% 단위로 움직이며 −/+ 버튼, 실시간 퍼센트,
50/100/150/200% 프리셋 칩이 있습니다. 스프라이트는 실제 확대 픽셀 크기(100%에서
152×98)로 렌더링되고, 클릭 영역, 캡션, 보고서 열, 상세 정보 패널이 이를 따릅니다.
크기를 바꾸면 저장된 위치가 자동으로 다시 제한됩니다.

## 캐릭터, 언어, 모션, 표시

톱니바퀴 패널에는 캐릭터(**Lumi** 또는 **Deepy**), 인터페이스 언어, 모션 켜기/끄기
(애니메이션 WebP 또는 정적 PNG), 표시 스위치, 테스트용 **자동**이 있는 15개 장면 미리보기
그리드도 있습니다. 첫 실행은 `navigator.language`를 따르며, 선택한 언어는 컴패니언
캡션도 전환합니다. 모션을 끄는 것이 노트북 배터리를 아끼는 가장 빠른 방법입니다.

## 선택적 데스크톱 창

같은 스프라이트는 같은 머신의 작은 항상 위 GTK 창에서 브라우저 밖에 떠 있을 수도 있습니다.
기본값은 꺼짐이며 Python 3, GTK 3, Pillow가 필요합니다:

```sh
sudo apt install python3-gi gir1.2-gtk-3.0 python3-cairo
python3 -m pip install --user Pillow
python3 desktop/companion.py
```

톱니바퀴 패널에서 **데스크톱 창**을 체크하세요. 행은 **연결됨**, **실행 중이 아님**,
**꺼짐**을 표시합니다. 브리지는 `127.0.0.1:37421`에만 수신하고 장면, 캐릭터, 크기,
애니메이션 플래그만 전달합니다. 프롬프트, 초안, 메시지, 세션 id, 모델 출력은 전혀 전달하지
않습니다. 데스크톱 창을 오른쪽 클릭하면 메뉴(character, size, always on top, reset
position, hide for an hour, quit)가 나옵니다. 실시간 업데이트를 위해서는 페이지가 열려
있어야 합니다. 전체 안내: [desktop.md](desktop.md).

## 끄기

- 설치하지 않고 스프라이트만 숨기기: 톱니바퀴 패널 → **표시** 끄기, 또는
  **설정 → 플러그인**.
- 번들 비활성화: 설정 → 플러그인, 또는 `dsh.profile.bundles`에서 제거.
- 완전히 제거: `dsh plugin --profile web remove dsh-pixel-companions`. UI가 원래대로
  돌아가며 프로필 밖의 파일은 건드리지 않습니다.
- 데스크톱 창은 별도 프로세스이므로 오른쪽 클릭 메뉴에서 종료하세요.

## 무엇을 보고 무엇을 보지 않는가

컴패니언은 공개 슬롯 props만 읽습니다. 세션 실행 상태, 현재 입력 단계, 대기 중 상호작용,
오류 플래그, 대화에 이미 표시된 확정 어시스턴트 답변입니다. 프롬프트 텍스트나 입력창
초안은 절대 읽지 않고, 자체 에셋 라우트와 옵트인 localhost 데스크톱 브리지 외에는 네트워크
호출을 하지 않습니다. 상세 정보와 보고서는 페이지에 남습니다. 데스크톱 창을 한 번도
활성화하지 않으면 페이지는 데스크톱 포트에 전혀 접속하지 않습니다.

## 키보드와 접근성

스프라이트와 톱니바퀴는 일반 포커스 가능 버튼입니다. **Tab**으로 도달하고 **Enter** 또는
**Space**로 설정 패널을 엽니다. **Escape**는 패널과 상세 보기를 닫고 바깥 클릭도
같습니다. 슬라이더와 선택 상자는 키보드로 조작할 수 있고, 보고서는 `aria-live`로
알리며, 상세 정보 패널은 레이블이 있는 대화상자입니다.

문제 해결: [troubleshooting.md](troubleshooting.md). 장면 규칙:
[scenes.md](scenes.md).
