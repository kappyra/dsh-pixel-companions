# Окно на рабочем столе

[English](../desktop.md) | [中文](../zh/desktop.md) | Русский | [Tiếng Việt](../vi/desktop.md) | [日本語](../ja/desktop.md) | [한국어](../ko/desktop.md)

`desktop/companion.py` — это **опциональное автономное окно на рабочем столе**, которое
показывает того же пиксельного компаньона вне браузера. Оно без рамки, всегда поверх остальных
окон, с попиксельной прозрачностью, перетаскивается левой кнопкой мыши и имеет меню по правому
клику. Это обычная программа на Python 3 (GTK 3 через PyGObject, Pillow и крошечный HTTP-bridge на
localhost); она не является плагином Harness и не меняет веб-интерфейс.

Окно — это спрайт, а веб-страница — мозг. Браузерная половина входит в обычный бандл и простаивает,
пока вы не включите **«Окно на рабочем столе»** в панели настроек компаньона. По умолчанию оно
выключено, поэтому страница без приложения для рабочего стола никогда не опрашивает локальный
порт. Обе половины должны работать на одной машине: bridge слушает только `127.0.0.1` и не имеет
аутентификации.

Статусы теперь отслеживают работу самого ассистента — выполняющийся вызов инструмента, поток
рассуждений или текста ответа, либо запрос в пути — и зеркало на рабочем столе показывает те же
сцены; протокол bridge не менялся. Браузер держит `success` и отчёт завершённого хода закреплёнными,
поэтому окно на рабочем столе зеркалирует `success` столько, сколько страница его держит; строка
отчёта и её панель подробностей существуют только в браузере.

## Требования

- Python 3.10+ на той же машине, что и страница в браузере.
- GTK 3 с PyGObject, привязки Cairo и Pillow:

```sh
sudo apt install python3-gi gir1.2-gtk-3.0 python3-cairo
python3 -m pip install --user Pillow
```

Именно `python3-cairo` делает окно попиксельно прозрачным. Без него (или без композитирующего
оконного менеджера) окно всё равно работает, но рисует спрайт на сплошном тёмном фоне.
`desktop/requirements.txt` перечисляет `PyGObject>=3.42` и `Pillow>=10` для pip; PyGObject обычно
берётся из дистрибутива, а не из pip.

Кадры спрайтов берутся из каталога `assets/` репозитория (`assets/girl/`, `assets/whale/`); в
рабочей копии ничего дополнительно скачивать не нужно.

## Запуск

Из корня репозитория:

```sh
python3 desktop/companion.py
# or
./desktop/run.sh
```

| Флаг | Значение |
| --- | --- |
| `--port PORT` | Порт bridge, по умолчанию `37421`. В этой версии страница всегда опрашивает `37421`, поэтому оставьте значение по умолчанию. |
| `--assets DIR` | Каталог ассетов; по умолчанию `assets/` репозитория. |
| `--scale 0.5\|…\|2.0` | Начальный масштаб спрайта, любое значение от `0.5` до `2.0` (с округлением до 1 %); значения вне диапазона завершают работу с ошибкой использования. Дальше внешним видом владеет меню по правому клику. |
| `--no-animation` | Запуск со статичным PNG вместо анимированного WebP. |
| `--lang en\|ru\|zh\|vi\|ja\|ko` | Зарезервировано. Окно не рисует текст, поэтому визуально это ничего не меняет. |
| `--stale-ms MS` | Окно устаревания в миллисекундах; тестовый хук, по умолчанию `10000`. |
| `--self-test` | Запустить headless-тест приёмки и выйти; дисплей не нужен. |

Окно запускается в состоянии `offline`, пока страница не пришлёт своё первое состояние. Настройки
(внешний вид, позиция, «всегда поверх») сохраняются в
`~/.config/dsh-pixel-companions/desktop.json`:

```json
{"character": "girl", "scale": 1, "animation": true, "alwaysOnTop": true, "x": 1200, "y": 600}
```

При первом запуске, если в этом файле нет сохранённого персонажа, его может выбрать первая
полезная нагрузка из браузера; после этого источником истины становится меню, а нагрузка только
задаёт сцену. Сохранённый `scale` принимает любое значение от `0.5` до `2.0` (с округлением до
1 %); старые значения `0.8` / `1` / `1.2` по-прежнему загружаются.

## Включение на стороне браузера

1. Убедитесь, что бандл включён в **«Настройки → Плагины»**, а веб-страница открыта (обычно
   `http://127.0.0.1:3080`).
2. Запустите окно на рабочем столе (или запустите его позже; страница опрашивает заново каждые
   10 секунд).
3. Откройте панель с шестерёнкой у компаньона и отметьте **«Окно на рабочем столе»**.

Строка показывает текущее состояние:

| Статус | Значение |
| --- | --- |
| **«Выкл.»** | Отключено. Страница вообще не опрашивает порт рабочего стола. |
| **«Не запущено»** | Включено, но на `127.0.0.1:37421` никто не отвечает. |
| **«Подключено»** | Окно на рабочем столе ответило на последний опрос; сцена зеркалируется. |

Пока **«Окно на рабочем столе»** включено, прямо под строкой появляется карточка предпросмотра: на
сцене в шахматную клетку показывается текущий спрайт ровно так, как его отрисовало бы окно на
рабочем столе (тот же персонаж, сцена, состояние анимации и пиксельное масштабирование), с
заголовком **«Предпросмотр окна на рабочем столе»**. Она показывает зелёное **«Подключено»** или
янтарное **«⚠ Не запущено — запустите `desktop/companion.py`»**. Карточка только для показа — ни
кнопки, ни изменения протокола — и исчезает, когда опция выключена; наведение на строку также
показывает подсказку о запуске.

Пока опция включена и соединение есть, страница опрашивает `GET /health` каждые 10 секунд,
отправляет своё состояние при смене сцены или внешнего вида и шлёт пульс раз в 4 секунды. Окно
подхватывает изменения примерно за 120 мс после отправки. Держите страницу открытой ради живого
состояния: если состояние не приходит больше 10 секунд (страница закрыта, перезагружается, сеть
заблокирована), окно показывает `offline` и продолжает работать.

## Контекстное меню

- **Character** — Lumi (`girl`) или Deepy (`whale`).
- **Motion** — анимированный WebP или статичный PNG.
- **Size** — 50 %, 75 %, 100 %, 125 %, 150 %, 200 %.
- **Always on top** — переключает подсказку окна держаться выше остальных.
- **Reset position** — возврат в положение по умолчанию в правом нижнем углу.
- **Hide for 1 hour** — скрывает окно; через час оно появляется автоматически.
- **Quit** — сохраняет настройки и завершает работу.

Перетаскивание левой кнопкой в любом месте спрайта двигает окно; позиция сохраняется. Пока окно
перемещают, Deepy переключается на свою анимацию без стола `roaming` и при отпускании возвращается
к зеркалируемой сцене; Whale Girl сохраняет спрайт своей сцены. Это только визуализация движения —
протокол bridge и набор из 15 сцен не меняются. Окно без рамки и без значка в трее; закрывается
правым кликом → **Quit**.

## Локальный bridge и граница приватности

Базовый URL: `http://127.0.0.1:37421`. Bridge — небольшой HTTP-сервер только на интерфейсе
loopback.

| Запрос | Ответ |
| --- | --- |
| `GET /health` | `200` `{"ok":true,"v":1}` |
| `POST /state` | `204`, без тела |
| `OPTIONS /state`, `OPTIONS /health` | `204` с заголовками CORS (`Access-Control-Allow-Origin: *`, методы `GET, POST, OPTIONS`) |
| Неизвестный путь | `404` |
| Некорректный JSON, неизвестная сцена, отсутствующая или неверная длина, тело больше 8 KB | `400` |

Полезная нагрузка `POST /state` (до 8 KB; неизвестные поля игнорируются):

```json
{"v": 1, "scene": "typing", "character": "girl", "scale": 1, "animation": true, "updatedAt": 1780000000000}
```

`scene` — один из 15 id сцен (`idle`, `typing`, `thinking`, `planning`, `reading`, `searching`,
`working`, `success`, `waiting`, `error`, `tired`, `coffee`, `sleeping`, `debugging`, `offline`). При
каждой отправке используется только `scene`; `character` принимается только при первом запуске,
пока персонаж не сохранён; `scale` и `animation` — дело меню рабочего стола; `updatedAt` —
информационное поле.

Через bridge проходит только состояние представления — **никакой текст промпта, текст черновика,
сообщения, id сессий, пути к файлам или вывод модели никогда не отправляются**. Bridge:

- слушает только `127.0.0.1`, не имеет аутентификации, cookie и TLS;
- отклоняет тела запросов больше 8 KB и любые тела с неизвестным id сцены;
- никогда не логирует полезные нагрузки запросов и не отдаёт файлы;
- разрешает источник браузера через CORS только для того, чтобы локальная страница могла отправлять
  данные.

## Устаревание и поведение offline

Окно помнит последнее полученное состояние и время его прихода. Если состояние не приходит больше
10 секунд, `effective_scene` становится `offline`; окно продолжает рендерить (и продолжает
анимировать эту сцену, когда анимация включена), пока не придёт свежая отправка. Сторона страницы
зеркалирует это: строка настроек откатывается к **«Не запущено»**, если опрос здоровья или отправка
не удались.

Ровно 10.000 с всё ещё считается свежим; переключение происходит сразу после этого. `--self-test`
проверяет эту границу с внедрёнными часами.

## Проверка

Headless-части проверены:

```sh
python3 -m py_compile desktop/companion.py
python3 desktop/companion.py --self-test
```

Self-test декодирует обоих персонажей × все 15 сцен в масштабах 0.5, 1.0 и 2.0, а также
опциональную анимацию Deepy `roaming`, проверяет размеры и длительности кадров, пишет 30 PNG первых
кадров во временный каталог вне репозитория как визуальное свидетельство, поднимает bridge на
эфемерном порту и проверяет `GET /health`, оба preflight-запроса CORS, корректный `POST /state`,
тела с некорректным JSON или неизвестной сценой (`400`) и неизвестный путь (`404`), а затем
проверяет правило устаревания в 10 секунд. Он печатает сводку `ok:` (`ok: … 92 animated decodes, 31 still decodes, 30 evidence PNGs, 260 checks`) и завершается с ненулевым кодом при ошибке.

Тест переключения при перетаскивании тоже проходит
(`whale: moving→roaming, released→idle; girl: no roaming`). Браузерная нагрузка проверена в headless-рендере React
(`scene=typing` → `success`), и в теле запроса нет ни черновика, ни данных сессии, а
headless-тест перетаскивания в браузере показывает, что кит переключается на `roaming` во время
перетаскивания и возвращается к сцене при отпускании (девушка не меняется).

Без графической сессии не проверить: само окно, попиксельную прозрачность на машине без моста
Cairo (там ожидается непрозрачный фолбэк), поведение always-on-top и перетаскивания, а также
позиционирование окна в Wayland.

## Ограничения

- Нужна графическая сессия (X11 или Wayland). У headless-сервера или обычного WSL нет дисплея;
  используйте проброс X или виртуальный дисплей либо запустите `--self-test`.
- Композиторы Wayland могут игнорировать запрошенную позицию окна, а некоторые бэкенды отклоняют
  запрос перемещения окна; сессия X11 — самая предсказуемая.
- Нет значка в трее, уведомлений, украшений окна и текста. Закрытие — через правый клик →
  **Quit** (или **Hide for 1 hour**).
- Страница должна оставаться открытой ради живого состояния. Окно — это цель отображения, а не
  второй клиент.
- Только на одной машине: bridge слушает только loopback и не аутентифицирует, поэтому не
  выставляйте порт наружу. Доступа к диалогу сверх крошечной полезной нагрузки у окна нет.
- Страница, отданная по HTTPS, обычно блокирует запросы к `http://127.0.0.1` как смешанный контент;
  используйте обычную страницу `http://127.0.0.1:3080`.

## Диагностика

| Симптом | Что проверить |
| --- | --- |
| Окно так и не появилось | Есть ли дисплей? Сначала запустите `python3 desktop/companion.py --self-test`; на сервере используйте проброс X или виртуальный дисплей. |
| `cannot listen on 127.0.0.1:37421` | Работает другой экземпляр компаньона. Закройте его (страница использует 37421, поэтому проще оставить порт по умолчанию). |
| Сплошной тёмный прямоугольник вместо прозрачности | Установите `python3-cairo`, используйте композитирующий оконный менеджер и запустите сессию X11 или композитируемый Wayland. Это ожидаемый непрозрачный фолбэк, а не падение. |
| Сцена остаётся `offline` | Страница открыта, бандл включён, **«Окно на рабочем столе»** отмечено? Проверьте `curl http://127.0.0.1:37421/health` и то, что страница и окно используют один порт. |
| Настройки говорят **«Не запущено»**, хотя окно открыто | Страница не может достучаться до bridge: проверьте порт, локальный firewall, другой процесс на 37421 или страницу, отданную по HTTPS (смешанный контент). |
| Окно не двигается в Wayland | Композитор может игнорировать запросы перемещения; попробуйте сессию X11 или перетаскивайте за другое место спрайта. |
| Окно на неверном мониторе или за экраном | **Reset position** в меню по правому клику; некоторые композиторы Wayland вообще игнорируют позиционирование. |
